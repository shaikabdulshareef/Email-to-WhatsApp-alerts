# 📧 Email-to-WhatsApp Alerts

An automated notification system that monitors incoming emails and sends real-time alerts to WhatsApp users.

## 🚀 Features

* Real-time email monitoring
* Automated WhatsApp notifications
* Message routing and processing
* JSON-based state management
* Python and Node.js integration
* Configurable alert workflows

## 🛠️ Tech Stack

* Python
* Node.js
* WhatsApp Web API
* JSON
* REST APIs

## 📂 Project Structure

```text
python_backend/     # Email processing logic
whatsapp_server/    # WhatsApp messaging service
run_all.py          # Main application runner
```

## ⚡ Installation

```bash
git clone https://github.com/shaikabdulshareef/Email-to-WhatsApp-alerts.git
cd Email-to-WhatsApp-alerts
npm install
python run_all.py
```

* Automated monitoring workflows
