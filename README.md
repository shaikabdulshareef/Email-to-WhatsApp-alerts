# Email-to-WhatsApp Alerts

An automated system that monitors incoming emails and sends WhatsApp notifications in real time.

## Features

* Email monitoring and processing
* WhatsApp alert notifications
* Automated message routing
* JSON-based state management
* Python and Node.js integration

## Technologies Used

* Python
* Node.js
* WhatsApp Web API
* JSON

## Project Structure

* `python_backend` – Email processing and automation logic
* `whatsapp_server` – WhatsApp messaging service
* `run_all.py` – Main application runner

## Installation

```bash
npm install
python run_all.py
```
